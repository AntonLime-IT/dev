# 🤖 Telegram Channel Bot + Claude AI

Бот для управления Telegram-каналом с интеллектуальным ассистентом на базе **Claude** (Anthropic).

---

## ✨ Возможности

| Функция | Команда |
|---------|---------|
| 📝 Создать пост | `/post <тема>` |
| 🔍 Анализ поста | `/analyze <ID>` |
| ✏️ Улучшить пост | `/improve <ID> \| <инструкции>` |
| 💬 Ответ на комментарий | `/reply <ID> \| <комментарий>` |
| 📤 Опубликовать в канал | `/publish <текст>` |
| 📊 Сводный анализ | `/summary` |
| 🤔 Вопрос Claude | `/ask <вопрос>` |
| 📋 Список постов | `/posts` |

## 🚀 Быстрый старт

### 1. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`
2. Следуйте инструкциям — получите **Bot Token**

### 2. Добавьте бота в ваш канал

1. Откройте настройки канала → Administrators
2. Добавьте бота как администратора с правами:
   - ✅ Post Messages
   - ✅ Edit Messages  
   - ✅ Delete Messages (опционально)

### 3. Узнайте ID канала

- Для публичных каналов: `@your_channel_username`
- Для приватных: используйте [@userinfobot](https://t.me/userinfobot) или перешлите любое сообщение из канала боту [@getidsbot](https://t.me/getidsbot)

### 4. Узнайте свой Telegram ID

Отправьте сообщение [@userinfobot](https://t.me/userinfobot) — он вернёт ваш числовой ID.

### 5. Получите Claude API Key

Зарегистрируйтесь на [console.anthropic.com](https://console.anthropic.com) и создайте API Key.

### 6. Настройте окружение

```bash
cd telegram_bot
cp .env.example .env
# Отредактируйте .env — вставьте свои токены
```

Содержимое `.env`:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCDefgh...
TELEGRAM_CHANNEL_ID=@mychannel
ANTHROPIC_API_KEY=sk-ant-...
ADMIN_IDS=123456789
```

### 7. Установите зависимости и запустите

```bash
pip install -r requirements.txt
python bot.py
```

## 📖 Примеры использования

### Создать и опубликовать пост

```
/post Топ-5 книг по продуктивности | пиши в дружелюбном тоне
```
→ Claude генерирует пост → кнопка **📤 Опубликовать** отправляет его в канал.

### Анализ существующего поста

1. Перешлите сообщение из канала боту — он сохранит его с ID
2. `/analyze 42` — получите подробный разбор

### Улучшить пост

```
/improve 42 | Сделай более живым, добавь юмор
```

### Ответ на комментарий

```
/reply 42 | Когда выйдет следующий пост?
```

### Произвольный вопрос

```
/ask Как часто нужно публиковать посты в Telegram-канале?
```

## 🔧 Конфигурация (`.env`)

| Переменная | Описание | По умолчанию |
|-----------|----------|--------------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от BotFather | **Обязательно** |
| `TELEGRAM_CHANNEL_ID` | ID/username канала | **Обязательно** |
| `ANTHROPIC_API_KEY` | API ключ Claude | **Обязательно** |
| `ADMIN_IDS` | ID администраторов (через запятую) | **Обязательно** |
| `CLAUDE_MODEL` | Модель Claude | `claude-opus-4-7` |
| `CLAUDE_MAX_TOKENS` | Макс. токенов в ответе | `4096` |
